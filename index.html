User Guide

About Calculator

A web calculator built with vanilla HTML, CSS, and JavaScript for the SMK Negeri 4 Tanjungpinang Class XII RPL Final Assessment 2026.

Key Operations

  • Addition (+): Computes the sum of two numbers.
  • Subtraction (−): Subtracts the second number from the first.
  • Multiplication (×): Multiplies two numbers (e.g. 124 * 56).
  • Division (÷): Divides first number by second. Division by zero triggers an error.
  • Clear (C): Resets display and calculation without clearing history.
  • Delete (del): Removes the last entered digit.
  • Toggle Sign (+/-): Inverts number sign (+ / -).
  • Result (=): Executes calculation with rounding up to 10 decimal digits.

Validation & Errors

Displays clear red alerts on screen when:

  • An operator is chosen without entering a number first.
  • The equals sign is pressed without the second number.
  • A number is divided by zero.
